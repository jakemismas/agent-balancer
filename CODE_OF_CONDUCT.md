# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, Discussions and any other project space.

## Report a problem

Report unacceptable behavior privately with the repository's
[private reporting form](https://github.com/jakemismas/agent-balancer/security/advisories/new),
and start the title with "Conduct". The maintainer reads every report, replies through the same
form, and keeps the reporter's identity private.
